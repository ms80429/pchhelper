# 게임 실측 가이드

목적: ChampDex와 우리 계산이 다른 8가지 메커니즘을 실제 게임으로 판정.
판정 기준은 "관측된 데미지가 우리 계산의 16개 값 중 하나인가" (`tests/calc/observed.test.ts`).
하나라도 벗어나면 우리 계산이 틀린 것 → 원인 조사 후 수정.

## 1. 준비

1. **대전 방식**: 상대 세트를 정확히 알아야 하므로 **프라이빗 배틀** (친구, 또는 본인 계정 2개 — Switch + 모바일).
   랭크/캐주얼은 상대 SP·성격·도구를 모르므로 쓸 수 없음.
   ⚠ 프라이빗 배틀이 1인 2계정으로 가능한지는 확인 안 됨. 안 되면 친구에게 부탁.
2. **맞는 쪽 = 내 포켓몬**. 내 포켓몬은 HP가 숫자로 보이므로 데미지 = 맞기 전 HP − 맞은 후 HP.
   (친구가 자기 포켓몬 HP를 읽어줘도 됨.)
3. **포켓몬 상태 화면을 사진으로 남기기**: 양쪽 포켓몬의 실수치 6개. 이것만으로도 실수치 공식 검증이 됨.

## 2. 정확도를 망치는 요인 (전부 피하기)

| 요인 | 대처 |
|---|---|
| 급소 | "급소에 맞았다" 메시지가 나오면 그 관측은 버리거나 급소로 기록 |
| 한 방에 기절 | 데미지가 HP보다 크면 숫자를 못 봄 → 내구 투자를 하거나 약한 기술 사용 |
| 등장 시 특성 | 위협(공격 −1), 날씨·필드 특성(가뭄, 모래날림 등). 기록하거나 없는 포켓몬 사용 |
| 회복 도구 | 먹다남은음식·자뭉열매 등은 턴 끝에 회복 → 방어측 도구는 데미지와 무관한 것으로 (Choice Scarf 등) |
| 랭크 변화 | 기술 부가효과로 랭크가 변하면 기록 |
| 다단히트·명중 | 단발 기술 위주로 |

## 3. 측정할 메커니즘 (우선순위 순)

| # | 메커니즘 | 구성 예시 (보유 포켓몬으로 대체 가능) | 판정력 |
|---|---|---|---|
| 1 | 객기 2배 + 화상 반감 무시 | 공격측을 내 쪽 도깨비불/전기자석파로 상태이상 → 공격측 객기 | 1회로 확정 |
| 2 | 탁쳐서떨구기 1.5배 | 내 포켓몬이 도구 소지 → 1타(1.5배) 관측, 도구 떨어진 뒤 2타(1배) 관측. 한 배틀로 둘 다 | 1회로 확정 |
| 3 | 바디프레스 (방어 사용) | 방어 투자한 공격측의 바디프레스 | 1회로 확정 |
| 4 | 속임수 (상대 공격 사용) | 공격 높은 내 포켓몬이 속임수를 맞음 | 1회로 확정 |
| 5 | 생명의구슬 / 달인의띠 | 기절하지 않을 조합으로 | 3~5회 |
| 6 | 리플렉터 | 내 쪽이 리플렉터 → 물리기 관측 | 5회 이상 |
| 7 | 두꺼운지방 | 두꺼운지방 포켓몬이 불꽃/얼음 기술을 맞음 | 10회 이상 (값 차이 1) |

5~7은 관측 1회로 거의 판정되지 않음. 여러 번 맞을 수 있게 HP 여유를 두거나 배틀을 반복.

## 4. 기록 형식 (채팅으로 주면 Claude가 `tests/calc/observed.json`에 추가) — 아래 숫자는 형식 예시

```
메커니즘: 객기
공격: 잠만보 / 고집 / SP 공격32 HP32 / 도구 없음 / 특성 두꺼운지방 / 상태: 화상
방어: 한카리아스 / 명랑 / SP HP2 공격32 스피드32 / 특성 까칠한피부
기술: 객기   날씨/필드/벽: 없음   랭크: 없음   급소: 아님
관측 데미지: 131   (맞기 전 HP 185 → 54)
상태 화면 실수치(선택): 잠만보 H267 A178 B85 C76 D130 S50 / 한카리아스 H185 ...
```

**추천**: 실제로 가진 포켓몬·세트 목록을 먼저 주면, Claude가 기절하지 않고 판정력이 높은 구체 조합과
예상 16개 값을 계산해 줌.

## 5. 결과 반영 규칙
- 관측이 우리 값 안에 있고 ChampDex 값 밖이면, 해당 ChampDex 골든 케이스를 "실측으로 반박됨"으로 기록
  (관측 id와 함께, 보고서에 표시). 이 처리는 사용자 확인 후에만 함.
- 관측이 우리 값 밖이면 우리 계산 버그 → 수정 후 재검증. 기대값을 관측에 맞춰 고치지 않음.
